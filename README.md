# Java Programs

This repository contains the Java programs I have practiced while learning Java. It covers basic concepts such as variables, data types, operators, input/output, conditional statements, loops, arrays, methods, and strings. I have added these programs step by step as I learn and practice different concepts.

It also includes Object-Oriented Programming concepts such as classes and objects, constructors, constructor overloading, method overloading, inheritance, polymorphism, encapsulation, and abstraction. I am using this repository to improve my coding and problem-solving skills and to keep track of my Java learning journey. I will continue adding more programs as I learn and practice new topics.
